# Rovina & Tejas: wedding website

Live site: https://tejasajoy.github.io/RovinaWedsTejas/

To change anything on the site, edit **`config.js`**. Step-by-step help is in **[EDITING-GUIDE.md](EDITING-GUIDE.md)**.

| File | What it is |
|---|---|
| `config.js` | All text, events, bride & groom, photos, fonts, colours and animations. **Edit this.** |
| `ocean.html` | Ocean sunrise design. Leave as is. |
| `sakura.html` | Sakura blossom design. Leave as is. |
| `shared.js` | Shared features (RSVP, gallery, Design panel). Leave as is. |
| `index.html` | Opens the design chosen in `config.js`. |
| `photos/` | Put your pictures here. |
| `EDITING-GUIDE.md` | How to edit, add photos, change fonts and go live. |

Hosted free on GitHub Pages.
